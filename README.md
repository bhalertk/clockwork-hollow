# 蒸汽機械城：探索試玩版

開啟 `index.html` 即可遊玩，不需要安裝套件或啟動伺服器。瀏覽器需允許 JavaScript；遊戲進度與聲音、震動偏好儲存在目前瀏覽器。

## 操作

- A／D 或方向鍵左右：移動。
- W、↑ 或空白鍵：跳躍；短按跳得較低，取得雙躍後可在空中再跳一次。
- 滑鼠左鍵：揮劍；空中按住上或下可上劈或下劈。
- Shift：蒸汽衝刺；E：互動、開門或休息。
- 擊中敵人三次可集滿修復蒸汽；生命不足時按 Q 回復一格。
- Tab：地圖；J：紀錄冊；H：操作說明；Esc：暫停；M：聲音開關。
- 倒下後按 R 從最近一次啟動或休息的休息站重新出發。

觸控裝置會顯示操作按鈕。右上角提供暫停、全螢幕、重新開始、畫面震動和聲音開關；重新開始會先要求確認並清除遊戲進度。

## 遊戲進度

遊戲會自動儲存能力、動力核心、Boss 勝利、記憶齒輪、已讀紀錄與休息站。啟動新休息站或在已啟動的休息站按 E，都會更新重生點。舊版存檔仍可使用；若瀏覽器封鎖儲存，畫面會提示無法儲存進度。

試玩版完成後按 R 會開始新一輪並清除進度；如果只想回頭探索，請在完成前從房間出口返回。

## 開發檢查

如已安裝 Node.js，可執行 `node tests/smoke.cjs` 檢查主要探索、Boss、重生與存檔流程。
